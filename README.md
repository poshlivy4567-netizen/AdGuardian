# AdGuardian

Приватный блокировщик рекламы и трекеров для Chromium-браузеров: Chrome, Opera, Яндекс Браузер, Edge и совместимых. Расширение работает на Manifest V3 и не отправляет историю посещений на внешний сервер.

## Что умеет

- Блокирует сетевую рекламу и трекеры по EasyList, AdGuard Russian и EasyPrivacy.
- Блокирует всплывающие окна и popunder: домены рекламных сетей из `$popup`-правил EasyList переводятся в сетевые блокировки навигации, а `window.open` на известные popunder-сети откатывается до открытия окна.
- Начинает защищать сразу после установки: в пакет уже включён срез из **29 500** проверенных правил (включая 1 000 блокировок всплывающих окон) и 42 точечных сетевых правила для известных рекламных платформ.
- Догружает ещё до **28 000** свежих динамических правил, не вытесняя пользовательские исключения. Это отдельная квота от встроенных static rulesets, поэтому одновременно работают до **57 532** правил, а не только 30 000.
- Автоматически обновляет подписки раз в сутки; обновление можно запустить вручную из popup.
- Скрывает типичные рекламные контейнеры Google Ads, Яндекс РТБ, AdFox, Taboola, Outbrain и MGID, включая доступные контейнеры в Shadow DOM. Рекламу РСЯ и Директа на сторонних площадках убирает по обёрткам самого блока, а не по его содержимому: сервер отдаёт такие вставки готовой разметкой и запирает их в закрытом Shadow DOM. На Яндекс Играх отдельно убирает рекламную колонку сервиса (карточки `data-name="adWrapper"` и их skeleton-заглушки) и промо-заставку приложения «Яндекс Игры», которая перекрывает игру блюром. Рекламные слои Игр не просто скрываются: расширение нажимает штатную кнопку «Закрыть»/«Пропустить» сайта, потому что иначе SDK не получит `onClose`, игра останется на паузе и перестанет принимать клики. Если сайт закрыть слой не даёт, слой возвращается на экран, чтобы игрок не остался с неработающим управлением. На YouTube отдельно убирает рекламу в ленте, баннеры и нажимает доступную кнопку пропуска в плеере.
- Позволяет поставить защиту на паузу для одного открытого сайта, не выключая расширение целиком.
- Показывает локальную статистику. Для приватности в ней хранятся домен, тип ресурса и время — не полный URL с параметрами или токенами.

## Установка распакованного расширения

1. Откройте страницу расширений браузера: `chrome://extensions`, `opera://extensions` или `browser://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта `AdGuardian`.
4. Закрепите AdGuardian на панели расширений.

После изменения файлов нажмите кнопку «Обновить» на странице расширений и перезагрузите открытую страницу сайта.

## Как устроена защита

| Слой | Объём | Назначение |
| --- | ---: | --- |
| `rules/ads_rules.json` | 42 | Ручные устойчивые правила для популярных рекламных сетей, видео-рекламы, `yandex.ru/an/count`, `yabs.yandex.ru` и креативов Директа (`avatars.mds.yandex.net/get-direct/`) |
| `rules/subscriptions.json` | 29 500 | Упакованный стартовый срез подписок, работает офлайн; включает 1 000 `$popup`-блокировок всплывающих окон |
| Динамические DNR-правила | до 28 000 | Свежая вторая часть подписок после автообновления, включая дополнительный срез popup-правил |
| `content/yandex-games.css` + `content/cosmetic.js` + `content/shadow-hook.js` | лёгкий | До JavaScript страницы скрывает внешние слои полноэкранной рекламы и промо-заставку Яндекс Игр, затем убирает известные контейнеры на всех сайтах, отслеживает host закрытых Shadow DOM по точным рекламным признакам и откатывает `window.open` на домены popunder-сетей |

Списки скачиваются параллельно. Если источник временно недоступен, сохраняется его последняя успешная версия; ошибка отображается в popup, а уже работающие правила не удаляются.

## Честные ограничения

Manifest V3 хорошо справляется с внешними рекламными запросами, но не даёт гарантированно вырезать любой рекламный контент. Реклама может быть сгенерирована самим сайтом, прийти из его cache/service worker или быть неотличима от обычного контента. AdGuardian не раскрывает закрытую Shadow DOM: при её создании через `attachShadow` он проверяет только точные рекламные маркеры (ссылки на счётчики Директа и РСЯ) и при совпадении скрывает доступный host. Декларативные shadow root-ы (`<template shadowrootmode="closed">`) так перехватить нельзя — их создаёт сам HTML-парсер, минуя `attachShadow`, и внутрь не достаёт ни CSS, ни JavaScript. Для них расширение опирается на селекторы обёрток в light DOM: скрыть host достаточно, потому что его shadow-дерево исчезает вместе с ним. В других случаях используйте «Пауза» для сайта, если фильтрация мешает его работе.

Индикаторы блокировок в распакованном расширении обновляются средствами отладки Chromium. Для опубликованной в магазине версии Chromium не предоставляет потоковое событие каждого срабатывания DNR — это ограничение платформы, а не доступ к данным пользователя.

## Разработка и проверка

Требуется Node.js 18+. Исходники подписок (`tools/*.txt`, ~4 МБ) не хранятся в репозитории — скачайте их первым шагом:

```powershell
node tools/download_filters.js
node tools/test_engine.js
node tools/test_runtime.js
node tools/build_subscriptions.js
```

Первый скрипт скачивает свежие EasyList, AdGuard Russian и EasyPrivacy в `tools/`. Второй проверяет исходники подписок, дедупликацию, лимиты и перевод ключевых ABP-модификаторов, включая `$popup`. Третий проверяет, что обновление правил не стирает исключения сайтов и корректно ужимается при заполненной квоте. Четвёртый заново создаёт `rules/subscriptions.json` и `lib/static-meta.js` из файлов `tools/`.

Запускайте все четыре команды перед загрузкой новой версии расширения.

## Структура

```text
AdGuardian/
├── background.js                 # состояние, обновления, DNR и исключения сайтов
├── content/cosmetic.js           # безопасная косметическая фильтрация
├── content/shadow-hook.js        # закрытый Shadow DOM и window.open в MAIN world
├── lib/filters.js                # ABP → DNR ($popup → main_frame), кэш и сборка правил
├── rules/
│   ├── ads_rules.json            # ручные правила
│   └── subscriptions.json        # сгенерированный стартовый срез
├── popup/                        # интерфейс управления
├── stats/                        # локальная статистика
└── tools/                        # загрузка, тест и сборка ruleset
```
