# AdGuardian

Приватный блокировщик рекламы и трекеров для Chromium-браузеров: Chrome, Opera, Яндекс Браузер, Edge и совместимых. Расширение работает на Manifest V3 и не отправляет историю посещений на внешний сервер.

## Что умеет

- Блокирует сетевую рекламу и трекеры по EasyList, AdGuard Russian и EasyPrivacy.
- Начинает защищать сразу после установки: в пакет уже включён срез из **29 000** проверенных правил и 32 точечных сетевых правила для известных рекламных платформ.
- Догружает ещё до **28 000** свежих динамических правил, не вытесняя пользовательские исключения. Это отдельная квота от встроенных static rulesets, поэтому одновременно работают до **57 032** правил, а не только 30 000.
- Автоматически обновляет подписки раз в сутки; обновление можно запустить вручную из popup.
- Скрывает типичные рекламные контейнеры Google Ads, Яндекс РТБ, AdFox, Taboola, Outbrain и MGID, включая доступные контейнеры в Shadow DOM.
- Позволяет поставить защиту на паузу для одного открытого сайта, не выключая расширение целиком.
- Показывает локальную статистику. Для приватности в ней хранятся домен, тип ресурса и время — не полный URL с параметрами или токенами.

## Установка распакованного расширения

1. Откройте страницу расширений браузера: `chrome://extensions`, `opera://extensions` или `browser://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта `AdGuardian`.
4. Закрепите AdGuardian на панели расширений.

После изменения файлов нажмите кнопку «Обновить» на странице расширений и перезагрузите открытую страницу сайта.

## Как устроена защита

| Слой | Объём | Назначение |
| --- | ---: | --- |
| `rules/ads_rules.json` | 32 | Ручные устойчивые правила для популярных рекламных сетей, видео-рекламы и `yandex.ru/an/count` |
| `rules/subscriptions.json` | 29 000 | Упакованный стартовый срез подписок, работает офлайн |
| Динамические DNR-правила | до 28 000 | Свежая вторая часть подписок после автообновления |
| `content/yandex-games.css` + `content/cosmetic.js` + `content/shadow-hook.js` | лёгкий | До JavaScript страницы скрывает внешние слои полноэкранной рекламы Яндекс Игр, затем убирает известные контейнеры на всех сайтах и отслеживает host закрытых Shadow DOM по точным рекламным признакам |

Списки скачиваются параллельно. Если источник временно недоступен, сохраняется его последняя успешная версия; ошибка отображается в popup, а уже работающие правила не удаляются.

## Честные ограничения

Manifest V3 хорошо справляется с внешними рекламными запросами, но не даёт гарантированно вырезать любой рекламный контент. Реклама может быть сгенерирована самим сайтом, прийти из его cache/service worker или быть неотличима от обычного контента. AdGuardian не раскрывает закрытую Shadow DOM: при её создании он проверяет только точные рекламные маркеры и при совпадении скрывает доступный host. В других случаях используйте «Пауза» для сайта, если фильтрация мешает его работе.

Индикаторы блокировок в распакованном расширении обновляются средствами отладки Chromium. Для опубликованной в магазине версии Chromium не предоставляет потоковое событие каждого срабатывания DNR — это ограничение платформы, а не доступ к данным пользователя.

## Разработка и проверка

Требуется Node.js 18+.

```powershell
node tools/test_engine.js
node tools/test_runtime.js
node tools/build_subscriptions.js
```

Первый скрипт проверяет локальные исходники подписок, дедупликацию, лимиты и перевод ключевых ABP-модификаторов. Второй проверяет, что обновление правил не стирает исключения сайтов и корректно ужимается при заполненной квоте. Третий заново создаёт `rules/subscriptions.json` и `lib/static-meta.js` из файлов `tools/`.

При обновлении файлов `tools/easylist.txt`, `tools/adguard_ru.txt` или `tools/easyprivacy.txt` запустите все три команды перед загрузкой новой версии расширения.

## Структура

```text
AdGuardian/
├── background.js                 # состояние, обновления, DNR и исключения сайтов
├── content/cosmetic.js           # безопасная косметическая фильтрация
├── lib/filters.js                # ABP → DNR, кэш и сборка правил
├── rules/
│   ├── ads_rules.json            # ручные правила
│   └── subscriptions.json        # сгенерированный стартовый срез
├── popup/                        # интерфейс управления
├── stats/                        # локальная статистика
└── tools/                        # тест и сборка ruleset
```
